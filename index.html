The slicer’s tools, for any file

The toolbar runs along the top of the canvas the way Bambu Studio’s does, and the keys are the same ones. Each tool works on every format Caliper opens, from a phone scan to an IFC building.

    Preview before you slice

    The Preview tab cuts the part at any layer, from the plate up, at the layer height you print with. Faces past the overhang limit turn red, and the sidebar checks the surface:

    • Closed or open. Every edge used by only one triangle is counted, so a hole in a scan shows up before the slicer guesses across it.
    • Volume and weight. Exact for a closed surface, with the weight in solid PLA beside it.
    • Overhang area. How much of the surface would print in mid-air at the limit you set.
    • Fits the plate. Choose a printer and the plate is drawn at its real size, with the part at its real size on top.

    22 file types, three ways in

    Mesh files already contain triangles. CAD files hold exact surfaces that a WebAssembly geometry kernel turns into triangles on your device. BIM files carry building elements, each one listed as a part.

    Install it, then double-click a model

    Caliper is a web app you can install. Installed, it opens in its own window with the top bar as its title bar, it keeps working without a connection, and your operating system offers it for STL, STEP, 3MF and the other model files.

    Use it in the browser

    In Chrome or Edge, use the install icon at the end of the address bar. On an iPhone or iPad, open the Share menu in Safari and choose Add to Home Screen.

    • Offline after the first visit The app and every geometry kernel you have used are kept on the device.
    • Opens files from your desktop Installed in Chrome or Edge, model files can be opened with Caliper from the file manager.
    • Nothing is uploaded Files are read in the browser tab. There is no server to send them to and no account to make.
    • Works on a phone The sidebar becomes a sheet and the toolbars scroll, so a part sent in a chat can be measured there.
